# Prize Master

تطبيق مكافآت للألعاب. هذه النسخة هي واجهة أولية فقط وليست نظام مكافآت حقيقياً بعد.

## إعداد المشروع
- `npm install`
- `npm run build`
- `npx cap add android`
- `npx capacitor-assets generate --android`
- `npx cap sync android`

## إعداد العجلة المعتمد
- 0 كوين: 50% — بنفسجي
- 1 كوين: 40% — أزرق
- 5 كوينز: 9% — ذهبي
- 10 كوينز: 1% — أحمر

لا يتم عرض النسب للمستخدم. لا تستخدم الرصيد المحلي أو نتيجة العجلة الحالية كرصيد حقيقي؛ يجب ربط Firebase وعمليات المكافآت الآمنة من جهة الخادم قبل الإطلاق.
